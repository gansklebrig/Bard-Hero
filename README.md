# Bard Hero

Rhythmusspiel für den Zynthian: Spiel die Melodie – die Band spielt den Rest.

- 13 eigene Lieder von gemütlich bis Speed Metal, jedes mit eigenem bewegten Hintergrund
- Hero-Modus (Controller-Tasten) und Barden-Modus (echte Töne), Stufen Leicht bis Meister
- Solo, Duell und Duett (Melodie + Bass) – Keytar, Gitarren-Controller (5er, 6er, 3 oben + 3 unten,
  Anschlag-Leiste), BeatStep, Zynthian-Tasten, Tastatur, Gamepad
- Mikrofon für Kommentatoren, Beamer per HDMI, Lautstärke am Drehregler
- Updates mit Aufräumen und Fortsetzen abgebrochener Installationen
